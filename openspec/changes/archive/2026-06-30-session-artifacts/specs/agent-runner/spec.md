## MODIFIED Requirements

### Requirement: Вызов агента
Харнесс SHALL вызывать агента командой `<agent.command> <agent.args...> <prompt>`, где prompt — последний позиционный аргумент. Вывод агента стримится в лог с префиксом `[AGENT] >`. Если вызывающий передаёт `io.Writer`, каждая строка вывода агента SHALL дополнительно записываться в этот writer (tee) — в реальном времени, без буферизации.

#### Scenario: Агент завершился успешно
- **WHEN** subprocess агента завершается с exit code 0
- **THEN** харнесс считает итерацию выполненной, сбрасывает счётчик consecutive_timeouts, переходит к restart

#### Scenario: Агент завершился с ошибкой (ненулевой exit code)
- **WHEN** subprocess агента завершается с ненулевым exit code
- **THEN** харнесс логирует предупреждение, считает итерацию выполненной (изменения могли быть сделаны частично), переходит к restart

#### Scenario: Writer передан вызывающим
- **WHEN** `Run()` вызывается с ненулевым `io.Writer`
- **THEN** каждая строка вывода агента пишется и в лог (`[AGENT] >`), и в переданный writer

#### Scenario: Writer не передан
- **WHEN** `Run()` вызывается с nil writer
- **THEN** поведение идентично текущему — вывод только в лог
