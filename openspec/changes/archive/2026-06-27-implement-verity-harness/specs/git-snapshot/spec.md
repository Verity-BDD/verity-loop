## ADDED Requirements

### Requirement: Baseline snapshot при старте
Харнесс SHALL фиксировать состояние рабочего дерева git в начале запуска как baseline. Baseline используется для построения diff в промптах итераций 2+.

#### Scenario: Фиксация baseline
- **WHEN** харнесс запускается перед началом цикла
- **THEN** текущее состояние рабочего дерева (включая незакоммиченные изменения) сохраняется как baseline_snapshot

### Requirement: Pre-agent snapshot перед каждым запуском агента
Харнесс SHALL фиксировать состояние рабочего дерева непосредственно перед каждым запуском агента.

#### Scenario: Фиксация pre-agent snapshot
- **WHEN** харнесс готовится запустить агента в итерации N
- **THEN** текущее состояние рабочего дерева сохраняется как pre_agent_snapshot итерации N

### Requirement: Rollback к pre-agent snapshot
При liveness failure после restart харнесс SHALL восстанавливать рабочее дерево до состояния pre_agent_snapshot текущей итерации.

#### Scenario: Успешный rollback
- **WHEN** liveness проверка упала после restart и существует pre_agent_snapshot
- **THEN** изменения агента из этой итерации отменяются, рабочее дерево возвращается к состоянию до запуска агента

#### Scenario: Rollback не применился чисто
- **WHEN** при попытке rollback возникает конфликт (агент мог сделать коммит)
- **THEN** харнесс логирует предупреждение, максимально откатывает что возможно, сообщает пользователю о необходимости ручного вмешательства

### Requirement: Diff для промпта
Харнесс SHALL уметь вычислять diff между baseline_snapshot и текущим состоянием рабочего дерева для включения в промпт.

#### Scenario: Вычисление diff
- **WHEN** строится промпт итерации 2+
- **THEN** diff содержит все изменения файлов относительно baseline_snapshot
