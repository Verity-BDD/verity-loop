## ADDED Requirements

### Requirement: Команда запуска
Харнесс SHALL предоставлять команду `verity-loop run`, запускающую полный цикл. Конфиг читается из `verity.yaml` в текущей директории. При старте харнесс SHALL инициализировать session recorder для записи артефактов в `.verity-sessions/` рядом с `verity.yaml`. Ошибка инициализации recorder'а не прерывает запуск.

#### Scenario: Запуск без аргументов
- **WHEN** пользователь выполняет `verity-loop run`
- **THEN** харнесс загружает `verity.yaml`, создаёт папку сессии в `.verity-sessions/`, инициализирует сервисы и входит в цикл

#### Scenario: Ошибка создания папки сессии
- **WHEN** `.verity-sessions/` недоступна для записи
- **THEN** харнесс логирует предупреждение и продолжает работу без записи артефактов

### Requirement: Предварительная проверка теста
Харнесс SHALL запускать тест сразу после инициализации сервисов. Если тест уже зелёный — завершиться с exit 0 без запуска агента.

#### Scenario: Тест зелёный при старте
- **WHEN** тест проходит до первой итерации агента
- **THEN** харнесс завершается с exit 0 без вызова агента

### Requirement: Ограничение числа итераций
Харнесс SHALL завершаться с exit 1 если тест не стал зелёным за `max_iterations` итераций.

#### Scenario: Исчерпание итераций
- **WHEN** пройдено `max_iterations` итераций и тест всё ещё падает
- **THEN** харнесс вызывает teardown, печатает номер последней итерации и вывод теста, завершается с exit 1

### Requirement: Успешное завершение
Харнесс SHALL завершаться с exit 0 когда тест становится зелёным.

#### Scenario: Тест стал зелёным
- **WHEN** `test_command` возвращает exit code 0 в любой итерации
- **THEN** харнесс вызывает teardown и завершается с exit 0

### Requirement: Обработка сигналов
Харнесс SHALL перехватывать SIGINT и SIGTERM для graceful shutdown.

#### Scenario: Получен SIGINT во время работы
- **WHEN** пользователь нажимает Ctrl+C в любой фазе (init, agent, restart)
- **THEN** харнесс дожидается завершения текущей операции (или убивает subprocess), вызывает teardown, завершается с exit 1
